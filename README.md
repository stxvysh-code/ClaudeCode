# arch-forest 🌲 — Arch Linux + KDE Plasma «Лесная ночь»

Автоматическая установка Arch Linux с KDE Plasma 6 под конкретный компьютер:
**MSI B450 · Ryzen 5 2600 · Radeon RX 570 · 16 ГБ · SSD Kingston 240 ГБ + HDD Toshiba 1 ТБ**.

Ты вставляешь флешку, вводишь **одну команду** — и через 20–60 минут получаешь готовую,
красивую и быструю систему: драйверы, игры, рабочие программы, оформление, автоматические
снимки для отката. Руками почти ничего настраивать не нужно.

## Честно о важном (прочитай!)

> ⚠️ **Оба диска будут полностью стёрты.** Windows и **все файлы** исчезнут. На диске D: сейчас
> около **140 ГБ данных** — если там есть что-то нужное (фото, документы, проекты, сохранения
> игр, кошельки, профили), **скопируй это на флешку/в облако заранее**.

- **Игры.** CS2 и Dota 2 работают на Linux нативно и отлично. Большинство одиночных игр из
  Windows запускаются через Proton (Steam) — проверить любую игру можно на
  [protondb.com](https://www.protondb.com). **Не работают** игры с жёстким античитом:
  Valorant, League of Legends, Fortnite, PUBG, Apex, Call of Duty, Battlefield 6.
- **DaVinci Resolve → Kdenlive.** Бесплатный DaVinci на Linux **не открывает обычные mp4**
  (H.264/H.265) и не работает со звуком AAC, а с RX 570 ещё и капризничает. Поэтому
  поставлен **Kdenlive** — современный, бесплатный, понимает любые видео. Если всё же хочешь
  попробовать DaVinci — см. [FAQ](#если-что-то-пошло-не-так-faq).
- **«Пиратский лаунчер».** Специальные пиратские сайты и лаунчеры я не ставлю и не советую.
  Но всё нужное для запуска **любых** Windows-игр и установщиков (.exe) есть: **Bottles**
  (запускает программу в изолированной «песочнице» — безопаснее для сомнительных файлов) и
  **Lutris**. Помни: в репаках часто бывают вирусы, а на этом компьютере будут рабочие аккаунты
  и деньги — сомнительное запускай только в Bottles.
- **Россия.** Discord и YouTube без VPN работают плохо — для этого стоит **Happ** (нужна твоя
  подписка/ключ от VPN-сервиса).
- **Vision** ставится из официального пакета разработчика для Arch Linux (AUR).
- **Шифрование диска** не включено (ты так выбрал), вход — автоматический.

## Шаг 0. Подготовка в Windows (15–20 минут)

### 0.1. Сохрани важное
Проверь диски C: и D:, рабочий стол, «Загрузки», «Документы». Пароли в браузере — включи
синхронизацию или экспортируй. Telegram, Steam (сохранения в облаке) и антидетект-профили
(обычно в облаке сервиса) — восстановятся после входа.

### 0.2. Сделай репозиторий публичным
Иначе установщик не сможет его скачать (паролей и личных данных в нём нет).
1. Открой https://github.com/stxvysh-code/ClaudeCode
2. **Settings** (вкладка сверху) → пролистай в самый низ, раздел **Danger Zone**
3. **Change visibility** → **Change to public** → подтверди.

> После установки можно вернуть репозиторий в приватный — системе он больше не нужен.

### 0.3. Скачай образ Arch Linux
1. Зайди на https://archlinux.org/download/ → в разделе **HTTP Direct Downloads** найди
   **Russia** → выбери, например, `mirror.yandex.ru`.
2. Скачай файл вида **`archlinux-2026.XX.XX-x86_64.iso`** (~1,4 ГБ).

### 0.4. Запиши образ на флешку (Rufus)
Флешка будет стёрта!
1. Скачай **Rufus**: https://rufus.ie → «Rufus x.x Portable».
2. Вставь флешку, запусти Rufus.
3. **Устройство** — твоя флешка (`USB DISK 2.0`, ~7 ГБ). Проверь, что это именно флешка!
4. **Метод загрузки** → кнопка **ВЫБРАТЬ** → файл `archlinux-...iso`.
5. **Схема разделов: GPT**, **Целевая система: UEFI (non CSM)**.
6. Нажми **СТАРТ**. Если спросит про режим записи — выбери **«Записать в режиме DD-образа»**
   → OK. Если предложит скачать дополнительные файлы — соглашайся.
7. Дождись «ГОТОВ». Флешку не вынимай.

## Шаг 1. Настройка BIOS (MSI, 5 минут)

1. Перезагрузи компьютер и сразу часто нажимай **Delete** — откроется BIOS MSI.
2. Нажми **F7** (расширенный режим, «Advanced»).
3. **Отключи Secure Boot** (иначе флешка не загрузится):
   `SETTINGS` → `Advanced` → `Windows OS Configuration` → `Secure Boot` →
   **Secure Boot → Disabled**.
   В том же `Windows OS Configuration` проверь: **BIOS UEFI/CSM Mode → UEFI**.
4. Отключи быструю загрузку: `SETTINGS` → `Boot` → **Fast Boot → Disabled**
   (и **MSI Fast Boot → Disabled**, если есть).
5. *(Необязательно, но полезно для игр)* Включи **A-XMP** (переключатель в левом верхнем углу):
   память заработает на своей полной частоте — на Ryzen это заметно поднимает FPS. Если после
   этого компьютер не запустится — он сам сбросит настройку через 2–3 попытки.
6. Нажми **F10** → **Yes** (сохранить и выйти).
7. Пока компьютер перезагружается, часто нажимай **F11** → появится меню загрузки →
   выбери строку **`UEFI: USB DISK 2.0 ...`** (обязательно с «UEFI»!) → Enter.

## Шаг 2. Установка (20–60 минут, почти без участия)

1. В меню флешки выбери первый пункт **`Arch Linux install medium (x86_64, UEFI)`** → Enter.
2. Подожди, пока появится строка `root@archiso ~ #` (чёрный экран с текстом — это нормально).
3. Интернет по кабелю подключится сам. Проверь:
   ```
   ping -c 3 archlinux.org
   ```
   Должно быть 3 строки с `time=...`. Если «Temporary failure» — проверь кабель и подожди 10 секунд.
4. **Введи команду установки** (аккуратно, по одному символу; `|` — это Shift + `\`):
   ```
   curl -sL https://raw.githubusercontent.com/stxvysh-code/ClaudeCode/HEAD/boot.sh | bash
   ```
   и нажми Enter.
5. Ответь на вопросы установщика:
   - **Имя пользователя** — Enter, чтобы оставить `styx` (или впиши своё, латиницей);
   - **Имя компьютера** — Enter (`styx-pc`);
   - **Пароль** — придумай, **латиницей**, введи дважды (символы не видны — так и должно быть).
     Пароль нужен только для установки программ, при включении он не спрашивается;
   - **Диски** — установщик сам предложит: SSD Kingston → система, HDD Toshiba → игры и файлы.
     Если всё так — нажми `y`;
   - **Подтверждение** — напечатай `YES` большими буквами.
6. Дальше всё идёт **само**: разметка, загрузка ~3 ГБ, драйверы, Plasma, программы, AUR,
   Flatpak, оформление, загрузчик, снимок «чистой системы». Можно отойти.
7. В конце появится **«✔ Установка завершена!»** → вынь флешку → нажми **Enter**.

> Если на каком-то шаге появилась красная ошибка — просто запусти ту же команду ещё раз
> (стрелка ↑ на клавиатуре вернёт её). Если повторяется — сфотографируй экран.

## Шаг 3. Первый запуск

1. Появится меню загрузки «Arch Linux · arch-forest» — через 3 секунды стартует само.
2. Заставка с логотипом MSI → вход в систему **без пароля**.
3. Через 10–30 секунд всплывёт уведомление **«Настраиваю оформление»** — экран моргнёт,
   появятся панели, обои, часы. Затем — **«Готово! Добро пожаловать»**.
4. Может открыться окно «Добро пожаловать в Plasma» — полезно полистать, потом закрыть.

| **Vision** | Меню → **Vision** → войди в аккаунт. |
| **Telegram / Discord** | Просто открой и войди (Discord в России — с включённым Happ). |
| **Мышь для игр** | *Параметры системы → Мышь* → **Профиль ускорения: Плоский (Flat)** — как в Windows с выключенным «повышенной точностью». |
| **Свои обои** | Положи картинки (например, с Pinterest) в папку **Изображения → Wallpapers**, затем ПКМ по рабочему столу → *Настроить рабочий стол и обои*. |
| **Figma** | Меню → **Figma** (откроется отдельным окном через Vivaldi). |
| **Офис** | Меню → **ONLYOFFICE** (документы, таблицы, презентации — совместимы с Word/Excel). |

Второй диск (HDD 1 ТБ) подключён в **`/mnt/data`**, в домашней папке есть ярлык **`HDD`**.
Там уже созданы папки `SteamLibrary`, `Games`, `Videos`, `Torrents`.

## Обновления и откат («машина времени»)

### Как обновляться
- В трее (справа вверху) есть значок **Arch-Update**: когда он показывает обновления — нажми
  на него, откроется окно с новостями Arch и обновлением. Просто следуй подсказкам.
- Или: меню → **«Обновить систему»**, или в терминале команда `update`.
- Обновляйся примерно **раз в неделю**. После обновления ядра — перезагрузись.

### Если после обновления что-то сломалось
Перед **каждой** установкой/обновлением система сама делает снимок (snapper).
1. Перезагрузи компьютер. В меню загрузки выбери **«Arch Linux snapshots»**.
2. Выбери снимок с датой **до** обновления (подписи вида `pre ... pacman -Syu`) → система
   загрузится в том состоянии (только для проверки, изменения не сохраняются).
3. Если всё работает — открой **Btrfs Assistant** (меню) → вкладка **Snapper** → выбери этот
   снимок → **Restore** → перезагрузись. Готово, система вернулась в прошлое.

Также есть снимок **«arch-forest: чистая установка»** — состояние сразу после установки.
Личные файлы (`/home`) снимками не затрагиваются — откат их не удалит.

## Если что-то пошло не так (FAQ)

<details>
<summary><b>Флешка не загружается / сразу стартует Windows</b></summary>

Проверь, что **Secure Boot выключен**, и в меню F11 выбирай пункт **с «UEFI:»**. Можно также
в BIOS: `SETTINGS → Boot → Boot Option #1` → флешка.
</details>

<details>
<summary><b>«Нет интернета» в установщике</b></summary>

Кабель должен быть подключён к компьютеру и роутеру. Подожди 10–20 секунд после загрузки
флешки и проверь `ping -c 3 archlinux.org`. Если не работает — `ip link` (должен быть
интерфейс `enp...` в состоянии `UP`).
</details>

<details>
<summary><b>«Не удалось скачать установщик»</b></summary>

Репозиторий должен быть **публичным** (см. шаг 0.2). Проверь, что команда набрана без ошибок.
</details>

<details>
<summary><b>В конце установки написано «Не всё поставилось автоматически»</b></summary>

Значит, какой-то программы не было на сервере в тот момент (бывает). После входа в систему
открой терминал (Ctrl+Alt+T) и посмотри список: `cat /var/log/arch-forest/failed.txt`.
Там прямо готовые команды, например `paru -S vision-browser` или
`flatpak install flathub org.onlyoffice.desktopeditors` — скопируй и выполни.
</details>

<details>
<summary><b>Оформление не применилось / хочу применить заново</b></summary>

В терминале: `/opt/arch-forest/firstboot.sh --force` — затем выйди из системы и войди снова.
Журнал: `~/.local/state/arch-forest/firstboot.log`.
</details>

<details>
<summary><b>Компьютер иногда зависает в простое (Ryzen 2000)</b></summary>

Известная особенность Ryzen 1000/2000 на Linux. В BIOS найди
**Power Supply Idle Control** (обычно `OC → Advanced CPU Configuration` или
`Settings → Advanced → AMD CBS`) → **Typical Current Idle**.
</details>

<details>
<summary><b>Тайлинг мешает</b></summary>

**Meta+Shift+T** — выключить/включить. Отдельное окно можно «освободить» клавишей **Meta+F**.
</details>

<details>
<summary><b>Монитор работает на 60 Гц, а не на 75</b></summary>

*Параметры системы → Экран и монитор* → **Частота обновления** → максимальная → *Применить*.
</details>

<details>
<summary><b>Хочу попробовать DaVinci Resolve</b></summary>

`paru -S davinci-resolve` (долго собирается). Учти: бесплатная версия на Linux не открывает
H.264/H.265 (обычные mp4 с телефона) и звук AAC — видео придётся сначала перекодировать.
Для RX 570 может понадобиться дополнительный OpenCL. Kdenlive таких ограничений не имеет.
</details>

<details>
<summary><b>Как запустить Windows-программу или игру (.exe)</b></summary>

- **Bottles** (рекомендуется для всего непроверенного): *Создать бутылку → Игры* → *Запустить файл* → выбери .exe.
- **Lutris**: `+` → *Добавить локально установленную игру* → раннер **Wine** → путь к .exe.
- **Steam**: *Игры → Добавить стороннюю игру* → в свойствах включи Proton.
</details>

<details>
<summary><b>Где журналы установки</b></summary>

`/var/log/arch-forest/install.log` — установка, `~/.local/state/arch-forest/firstboot.log` —
первый вход.
</details>

## Как это устроено

```
boot.sh              ← команда с флешки скачивает репозиторий и запускает install.sh
install.sh           ← этап 1 (с флешки): вопросы, диски, pacstrap, fstab
lib/chroot-setup.sh  ← этап 1б (внутри новой системы): язык, пользователь, GRUB, снимки,
                       службы, AUR (paru), Flatpak, оформление
firstboot.sh         ← этап 2 (первый вход): глобальная тема, панели, обои, частота монитора
config.sh            ← настройки: имя по умолчанию, часовой пояс (Asia/Barnaul), раскладки, ядро
packages/*.txt       ← списки программ (можно добавить своё перед установкой)
files/               ← системные настройки (zram, звук, initramfs, обновление GRUB…)
home/                ← личные настройки (zsh, Konsole, KWin, тайлинг, раскладки…)
theme/               ← тема: цвета, Kvantum, Konsole, раскладка Plasma, тема GRUB
```

**Разметка SSD:** EFI 1 ГБ (FAT32) + Btrfs с подтомами `@` (система), `@home`, `@snapshots`,
`@var_log`, `@pkg`. **HDD:** ext4 `DATA` → `/mnt/data`.

**Благодарности и лицензии:** обои «Path» и «One Stands Out» — Risto Saukonpää (KDE, LGPL-3.0);
Kvantum-тема основана на [Graphite](https://github.com/vinceliuice/Graphite-kde-theme)
(Vince Liuice, GPL-3.0); иконки [Colloid](https://github.com/vinceliuice/Colloid-icon-theme);
цвета вдохновлены [Everforest](https://github.com/sainnhe/everforest).
